# TokenFuse 1.26.0

A minor release. Every door now judges a tool call's own arguments, the streamed-call judge is hardened, the price book gains current rows, the trace and the FOCUS export carry cache and reasoning tokens, and three dependency advisories are closed.

It covers everything merged since v1.25.0: pull requests #526 to #535 and the commits they carry.

## Upgrade

1. Change the image tag. No migration is listed for this release.
2. The trace and the FOCUS export gain cache and reasoning token fields (#528). A consumer that reads the export strictly should accept the new columns.

## Security

- **Every door judges a tool call's own arguments (invariant 121).** The check, the MCP broker and the streamed judge each read the arguments of the call they are deciding, not an argument carried from another call.
- **The streamed judge is hardened.** Every closing message is its own statement of a call; a closing message no longer replaces what the deltas built; every name a call was given is judged with every argument text; the statements kept per call are bounded, and a name past the cap is judged as unknown.
- **Dependency advisories closed.** wasmtime moves to 49.0.6 for RUSTSEC-2026-0566, 0567 and 0573 (#529). url 2.5.9 and form_urlencoded 1.2.3 for RUSTSEC-2026-0592 (#532). quinn-udp 0.5.16 for RUSTSEC-2026-0538 (#527).

## Pricing

- Rows for gpt-6.2-astra and gpt-6.2-sol (#531).
- Bedrock profiles for Claude 5 and Fable, OpenRouter rows for Fable and Opus 4.5 to 4.7, and Gemini 4 API ids.
- Gemini 4 Carbon and Argon priced at the current list rate; derived Bedrock ids are marked as derived.
- The long-prompt tier list holds the Haiku 5.5 profiles.

## Observability

- Cache and reasoning tokens on the trace, FOCUS `x_` columns, and `--spec 1.5` for the FOCUS export (#528).

## Maintenance

- CI action bumps, and documentation brought in line with the code, including the suite's test count.
