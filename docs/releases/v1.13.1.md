# TokenFuse 1.13.1

A patch release with one fix on the tool path and one dependency move.

- The MCP broker now sends Wardryx a tool call's arguments only when they fit
  Wardryx's own 12 KiB bound. Before, a call with 12 to 16 KiB of arguments was
  sent whole, refused by Wardryx with a 400 and no verdict, and then decided by
  the failmode alone: under the default `open`, allowed with no policy decision.
- `datafusion` moves from 44 to 55, which drops `parquet` 53 and the `thrift`
  crate it pulled in (Dependabot alert #2, moderate).

Nothing is renamed or removed and no environment name is added. The umbrella crate
and both client SDKs move to 1.13.1 with no client behavior change.

## Fixed

- **The tool-call argument cap equals the policy plane's bound (#423, invariant
  100).** `TOOL_CALL_ARGUMENTS_CAP_BYTES` goes from 16 KiB to 12 KiB, equal to
  Wardryx's `MaxToolArgumentsBytes`. Exactly 12,288 serialized bytes of arguments
  are sent whole; 12,289 and more are sent as `arguments_truncated: true` with no
  `arguments`, which Wardryx accepts and decides on. The failmode is unchanged: it
  still decides a call the policy plane could not answer. This only makes sure the
  policy plane can answer every call it is shown. A deployment whose Wardryx policy
  never reads tool arguments sees no change in verdicts.

## Changed

- **`datafusion` 44 -> 55 (#422).** `parquet` moves to 59, which has no `thrift`
  dependency, so the `thrift` advisory no longer applies. The trace store, the SQL
  query, the FOCUS export, the backtest and the keys and outcomes reports compile
  unchanged. Building from source now needs Rust 1.94 or later (the workspace
  `rust-version`); the published images are built with the current stable toolchain.

## Upgrade

Replace the image tag. No configuration changes.

## Not proven

- A live Wardryx deciding a 13 KiB tool call through a released gateway image: the
  boundary is held by the integration tests against a stub PDP that answers as
  Wardryx does, not by a run against a deployed Wardryx.
- The two constants stay equal only while someone keeps them so: the estate-gates
  check that pairs them across the two repositories is added separately.
