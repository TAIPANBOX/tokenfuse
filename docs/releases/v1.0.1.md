# TokenFuse 1.0.1

Three money-path corrections, each a defect in what the gateway said a run
had spent or in what it told the operator; no name, default, route or wire
body of `compat/1.0.json` changes. Reviewed as a T3 change (a second model
read the whole diff before it was pushed; its four findings are in it).

## Fixed

- **An OpenAI cached token was priced twice** (tokenfuse#267). OpenAI's
  `prompt_tokens` includes `prompt_tokens_details.cached_tokens`; the parser
  copied both whole, so every cached token was billed at the full input rate
  and again at the cache-read rate: a 950/128 `gpt-4o` call settled 2535
  micro-USD against the provider's 2215, +14.5 % and more with a higher hit
  ratio, inside the run's budget as spend nobody was billed. The cached subset
  is now netted out of the prompt count, on every chunk of a stream (a later
  chunk without the details cannot bring it back), and a subset past the
  prompt count nets to zero rather than wrapping.
- **A one-hour cache write was priced at the five-minute rate** (tokenfuse#282).
  Anthropic bills a 1-hour cache write at 2x input and a 5-minute one at
  1.25x; the gateway priced the whole `cache_creation_input_tokens` at the
  5-minute rate, 37 percent under on the Claude Code call INT-2 of the 1.0
  proving run measured (0.176436 against Claude Code's own 0.281716 USD). The
  1-hour subset (`usage.cache_creation.ephemeral_1h_input_tokens`) is now
  priced at a 1-hour rate the book derives as 1.6x the 5-minute one, exact for
  every Anthropic model, and publishes as `cache_write_1h_per_mtok_microusd`
  in `contracts/tokenfuse-constants.json` (additive; the OpenAI entries carry
  their single write rate there, since no OpenAI usage reports a 1-hour
  subset).
- **A reachable provider that refused the call was silent on the bus**
  (tokenfuse#260). A 429 or a 5xx passed through and settled right, and no
  agent-event was written, so a notifier never heard about a provider refusing
  every call. Now one `dependency_failed` per refusal at a new stage,
  `response`, with the status and the model in `detail`, for the statuses
  that are the provider's own failure: every 5xx, 429, 408, and 404 or 400
  (how providers answer a retired model id). A caller's own 401, 403, 413,
  415 or 422 pages nobody. A refused stream whose body then breaks is one
  event. The money rules are untouched.

## What to know on the way in

- The version is the promise: nothing in `COMPATIBILITY.md` moves. The
  client packages version with the gateway and are 1.0.1 with no change in
  them.
- **An OpenAI row's `input_tokens`** in the Parquet trace, the Cloud and the
  FOCUS export is now the prompt count net of the cached subset, where 1.0.0
  wrote the whole prompt; a sum of tokens across the boundary is a sum of two
  definitions, and a fully cached prompt with no completion now reads as zero
  tokens beside a nonzero cost, which the FOCUS export labels `estimated`.
  The cache columns that would make this exact are invariant 6 work.
- **Notifiers**: heraldyx renders the new stage with the right money sentence
  from its next release (heraldyx#66); an older heraldyx describes a refusal
  as "could not be reached ... nothing was charged", which is wrong for a
  refusal that reported usage. agent-passport's SPEC names the stage
  (agent-passport#65).
- The pre-flight estimate still reserves cache writes at the 5-minute rate
  (it does not know the TTL), so a 1-hour-heavy call can settle above its
  reservation; the ledger settles the true figure.

## Proven

- Every fix red first on the unfixed tree, then green; ten mutants, each
  caught by a named test (the netting removed, a wrapping subtraction, the
  subset at the wrong rate, the subset double-counted, the ratio dropped, each
  emission removed, the condition inverted, the stream arm's guard reverted,
  the status class widened). Sixteen scenarios in three `features/` files,
  each bound to a test. 1240 tests.
- Not proven on a real provider: the 1-hour figure is asserted against Claude
  Code's own number for the INT-2 call, not re-measured against Anthropic's
  bill; the OpenAI multi-chunk shape is a reading of the parser, not a
  provider observed emitting it.
