# TokenFuse 1.14.0

A minor release: the gateway now holds budgets until it has read its control plane, judges streamed tool calls, refuses on the bus the keys it refuses, and reports PII it lets through. The Cloud names every model a run used and keeps spend that a stop would have lost.

It covers everything merged since v1.13.1: the v1.13.2 patch (its container images shipped; its musl binaries did not publish, see below) and the twelve pull requests after it.

## Added

- **PII the scanner finds and lets through is on the call's trace row and in the fleet view (invariant 106).** Kinds and counts only, never the matched text. The trace gains an appended nullable `pii_findings` column; the Cloud reads it per run (`pii_calls` in the run summary). PR #433.
- **A refused client key is on the bus (invariant 105).** A missing or unknown `x-fuse-key` now emits one `identity_mismatch` event with a reason (`missing_key` or `unknown_key`) and a fingerprint of the presented value, never the key. A call that names no agent is filed under the reserved subject `agent://unidentified.invalid/caller`. One event per source a minute, sixty a minute for the gateway. The caller's `401` is unchanged. PR #432.
- **IBANs are a PII kind (invariant 110).** `pii_iban` finds an IBAN by its shape, checks its country code and length against the ISO 13616 registry, and checks its mod-97 digits. PR #437.
- **A run names every model it used (invariant 111).** The Cloud keeps each run's models with their calls and spend, how often the model changed, and whether a gateway refused calls on the run because it was killed there. PR #438.
- **The FOCUS export names the price basis and the PII let through.** Two appended columns, `x_price_basis` (`known` or `fallback`) and `x_pii_findings`. PR #436.
- **The exit flush (invariant 112).** On SIGTERM or SIGINT the gateway stops taking calls, then delivers what it still holds to the Cloud within five seconds, and logs a warning with the count of records the Cloud did not receive. PR #439.

## Fixed

- **A gateway admits nothing a budget governs until it has read its control plane's money state (invariant 103).** A gateway that started before its control plane admitted calls for a unit already over its monthly cap and for a run already past its budget. Until the seed is read, a call carrying `x-fuse-run-id` is answered `503 seed_pending` (retryable), or marked in `x-fuse-would-block` in shadow. PR #429.
- **A streamed answer's tool calls are judged as a buffered answer's are (invariant 104).** A streamed `write_file` after a web read reached the agent and ran, because the streamed path had no taint judgement. Both wires now judge the streamed tool calls, with the same inputs as the buffered path. Shadow mode records the would-be refusal. PR #430.
- **Brokered `tool_call` records carry the caller's run id (invariant 108).** PR #435.
- **`openai/` ids are priced at OpenAI's list rate, and the book gains the GPT-4.1 rows.** PR #434.
- **Digits that are part of a decimal number are not cards.** A probability such as `0.12345678901234567` no longer reads as a 17-digit card. PR #437.
- **The control-plane page renders run fields as text (invariant 102).** This is the v1.13.2 fix, carried here. PR #428.
- **The `rustls` move to 0.23.46 and the wasmtime move to 49.0.3.** `rustls` moved in v1.13.2 (RUSTSEC-2026-0346 to -0349). `wasmtime`, the optional WASM policy sandbox that no shipped image enables, moved from 49.0.2 to 49.0.3 for twelve advisories (RUSTSEC-2026-0353, -0356 to -0364), a lockfile-only change.

## Changed

- **Streamed tool calls can now be refused.** A stream whose tool call the taint policy denies is cut before the call reaches the agent, on both wires. Clients that relied on a streamed denied call running are affected; this is the policy as configured, not a new rule.
- **A budget-governed call can get `503 seed_pending` at startup.** Only during the window before the gateway has read its control plane. The gateway retries in the background. Deployments with no control plane configured are unaffected.
- **The FOCUS export and the trace schema gain columns.** Old files keep reading; the new columns are nullable.
- **The Cloud's run rows gain `models`, `model_switches`, `model_millis`, `last_admitted_model` and `killed_by_gateway`.** Additive; existing readers are unaffected.
- **The price book prices `openai/` ids and holds the GPT-4.1 rows.** A cost that was charged at the fallback rate can change.
- **The CI apt step fetches only the `Packages` indexes, and the release musl step gets twelve minutes (#441).** The release workflow changes, not the product.
- **The repository's own guard against owner quotes (#424).** Public files carry no quotes of the owner; the gate that checks this is new.

## v1.13.2 and the musl binaries

v1.13.2 published its container images. Its musl binaries never published, because of the apt snapshot outage during its release run. #441 narrows the apt fetch and gives the musl step twelve minutes, so the v1.14.0 musl binaries should publish; check the release page before relying on them.

## Upgrade

Replace the image tag with `v1.14.0`, or the binary with the musl build once it is on the release page. Compose stacks: the three image pins in `cloud/docker-compose.yml` move to `v1.14.0`.

No environment name, route or header is removed.

What an operator will see on upgrade:

- A gateway restarted while its control plane is down answers budget-governed calls `503 seed_pending` until the seed is read. This is the intended refusal, not a fault.
- A stream carrying a denied tool call ends with the refusal, not with the call.
- Trace files and FOCUS exports carry new nullable columns. Readers that select columns by position must read by name.

## Not proven

- No live provider call was made on the new images for this release. The streamed judgement, the seed gate and the exit flush are tested through the gateway with stub upstreams and stub control planes, not against a provider or a deployed Cloud.
- The exit flush has been measured against a stub Cloud that never answers; the five-second bound is the measured behaviour of that stub, not a guarantee against a slow real one.
- The seed gate's restart case was reproduced on a forge host on 2026-10-14; the release tests do not restart a real control plane.
- The per-run model list and the kill propagation are tested against the Cloud's ingest path; a multi-gateway fleet has not been run.
- The musl binaries for v1.14.0 are not proven until they appear on the release page.
- Coverage is not measured for the Rust crates; CI compiles and runs the tests, and no coverage figure is published.
